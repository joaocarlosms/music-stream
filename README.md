## 🎯 Visão Geral

MusicStream é uma plataforma web que permite aos usuários criar e gerenciar playlists personalizadas, fazer upload de suas próprias músicas e desfrutar de uma experiência de streaming musical intuitiva e moderna.

## ✨ Características

- **🎵 Gerenciamento de Playlists** - Crie, edite e exclua playlists personalizadas
- **📤 Upload de Músicas** - Adicione suas próprias músicas à plataforma
- **▶️ Player Integrado** - Interface de reprodução amigável
- **👤 Perfil de Usuário** - Mantenha controle sobre suas criações
- **📱 Design Responsivo** - Interface otimizada para diferentes dispositivos

## 🚀 Instalação

### Pré-requisitos

- JDK 11 ou superior
- Servidor de aplicação Java EE (Tomcat)
- MySQL ou outro banco de dados relacional
